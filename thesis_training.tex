\section{Training}

Training optimises the shared policy parameters $\theta$ and the centralised critic parameters
$\phi$ against the analytical link-utilisation model rather than the packet-level simulator:
given the paths committed so far, arc loads and utilisations follow in closed form from
$\boldsymbol{\ell} = \mathbf{R}^{\!\top}\mathbf{r}$ and $u_e = 100\,\ell_e/c_e$, so an episode
costs milliseconds instead of the minutes an \mbox{ns-3} run requires. The simulator is reserved
for judging the finished policy and is never part of the gradient path.

An episode is a complete routing of one demand matrix: flows with $r_i > 0$ are ordered by
decreasing rate and routed hop by hop, giving $K = \sum_i L_i$ decisions. Because the per-hop
reward telescopes, the episode return is exactly the negated objective,
\begin{equation}
\sum_{k=0}^{K-1} R^{(k)} \;=\; -\,U_{\max} \;-\; \beta \sum_i \bigl(L_i - L_i^{\mathrm{sp}}\bigr),
\end{equation}
so no terminal bonus is required and the trained quantity is the one on which OSPF is scored.
The objective is the expected return over a \emph{distribution} of demand matrices,
\begin{equation}
J(\theta) = \mathbb{E}_{\mathbf{r} \sim \mathcal{D}_{\mathrm{train}}}
\mathbb{E}_{\tau \sim \pi_\theta}\!\left[\sum_{k} \gamma^{k} R^{(k)}\right],
\qquad
\mathcal{D}_{\mathrm{train}} = \bigl\{\alpha\,\mathbf{r}^{(t)} : \alpha \in \mathcal{A},\;
t \in \mathcal{T}_{\mathrm{train}}\bigr\},
\end{equation}
where $\mathcal{T}_{\mathrm{train}}$ is the earlier window of the measured SNDlib series and
$\mathcal{A} = \{2,3,4\}$ scales the demand into the congested regime in which routing decisions
matter. Evaluation draws from the disjoint later window $\mathcal{T}_{\mathrm{test}}$, so results
measure temporal generalisation.

Each iteration collects $T$ decision steps under $\pi_{\theta_{\mathrm{old}}}$, resetting to a
newly drawn matrix at every episode end. Advantages use generalised advantage estimation with a
bootstrap at the truncation point, and are standardised across the batch so that the gradient
scale does not depend on which load levels were sampled:
\begin{equation}
\delta^{(k)} = R^{(k)} + \gamma V_\phi\bigl(s^{(k+1)}\bigr)\bigl(1-\mathrm{done}^{(k)}\bigr) - V_\phi\bigl(s^{(k)}\bigr),
\qquad
\hat{A}^{(k)} = \sum_{j\ge 0} (\gamma\lambda)^{j}\delta^{(k+j)},
\qquad
\tilde{A}^{(k)} = \frac{\hat{A}^{(k)} - \mu_{\hat{A}}}{\sigma_{\hat{A}} + 10^{-8}} .
\end{equation}
The batch is then reused for $E$ epochs of minibatch descent on
\begin{equation}
\mathcal{L}(\theta,\phi) =
-\,\mathbb{E}_{k}\Bigl[\min\bigl(\rho^{(k)}\tilde{A}^{(k)},\,
\mathrm{clip}(\rho^{(k)},1-\varepsilon,1+\varepsilon)\tilde{A}^{(k)}\bigr)\Bigr]
+ c_v\,\mathbb{E}_{k}\Bigl[\bigl(V_\phi(s^{(k)})-\hat{V}^{(k)}\bigr)^{2}\Bigr]
- c_e\,\mathbb{E}_{k}\Bigl[\mathcal{H}\bigl[\pi_\theta(\cdot\mid o^{(k)},\mathbf{m}^{(k)})\bigr]\Bigr],
\end{equation}
with $\hat{V}^{(k)} = \hat{A}^{(k)} + V_\phi(s^{(k)})$ and importance ratio
$\rho^{(k)} = \pi_\theta(a^{(k)}\mid o^{(k)},\mathbf{m}^{(k)}) /
\pi_{\theta_{\mathrm{old}}}(a^{(k)}\mid o^{(k)},\mathbf{m}^{(k)})$. The action mask enters both
policies, so the entropy term explores only among \emph{legal} next hops and cannot place mass on
hops the loop-freedom constraints forbid. Updates use Adam under global gradient-norm clipping at
$g_{\max}$, which is necessary because the reward is a maximum over arcs and a single hop that
creates a new bottleneck yields a large, sparse gradient. All router agents update the same
$\theta$, so every decision anywhere in the network contributes a gradient term and the effective
sample size per iteration is $T$ decisions rather than $T/N$ per-agent trajectories.

Progress is monitored on a held-out set $\mathcal{H}$ of unseen matrices under the deterministic
policy $a = \arg\max_a \pi_\theta(a\mid o,\mathbf{m})$, tracking the mean bottleneck improvement
over OSPF and the strict win rate,
\begin{equation}
\overline{\Delta} = \frac{1}{|\mathcal{H}|}\sum_{\mathbf{r}\in\mathcal{H}}
\bigl(U^{\mathrm{OSPF}}_{\max}(\mathbf{r}) - U^{\pi_\theta}_{\max}(\mathbf{r})\bigr),
\qquad
w = \frac{1}{|\mathcal{H}|}\Bigl|\bigl\{\mathbf{r}\in\mathcal{H} :
U^{\pi_\theta}_{\max}(\mathbf{r}) < U^{\mathrm{OSPF}}_{\max}(\mathbf{r}) - \varepsilon_0\bigr\}\Bigr|,
\end{equation}
with tolerance $\varepsilon_0 = 0.5$ percentage points so that numerically insignificant
differences count as ties. A myopic greedy best-response, which at each hop takes the admissible
neighbour minimising the resulting bottleneck, is scored on the same matrices as an intermediate
reference: it bounds what purely local, non-anticipatory decisions achieve, so the gap to
$\pi_\theta$ isolates the value of learned, congestion-anticipating behaviour. Final parameters
are exported for \mbox{ns-3} evaluation, where the same deterministic rollout produces the
per-demand paths installed as static routes.
